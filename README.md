# Wine Serbia — Validation-First Product Repository

## Status

**VALIDATE BEFORE BUILDING**

This repository is intentionally in a pre-product validation phase.

The current hypothesis is not “another winery directory” and not a full wine marketplace.

> **Working wedge:** verified winery experience → QR Wine Passport → repeat-purchase / measurable winery ROI.

## Why

Serbia already has strong winery discovery coverage through local directories, Google and global wine/tourism platforms. The unresolved opportunity is whether a product can create **measurable incremental value for wineries** after discovery and tasting.

## Current priorities

1. validate winery pain and payer;
2. validate consumer visit/reorder workflow;
3. validate QR Passport usage;
4. validate 30/60-day repeat-purchase signal;
5. validate data-maintenance burden;
6. only then authorize MVP implementation.

## Do not build yet

- full marketplace;
- multi-winery cart;
- payment orchestration;
- warehouse/fulfillment;
- native mobile app;
- advanced ML recommender;
- public review network;
- winery POS/CRM replacement;
- regional alcohol commerce.
