# 30 / 60 / 90 Day Action Plan

## Days 1–30 — Prove the problem, not the code

### Week 1

**Founder / research**
- build target list 40 wineries;
- segment by region/digital maturity;
- recruit 10 consumers;
- prepare interview forms and assumption ledger;
- contact legal/accounting expert for scoped future-payment/tourism consult (do not buy full memo yet).

**Engineering**
- no product code;
- simple research database/spreadsheet;
- optional landing/Figma prototype.

### Week 2

- 8–10 winery interviews;
- 8 consumer interviews;
- manually test two trip-planning cases;
- collect exact current booking/reorder workflows;
- record onboarding effort.

### Week 3

- remaining interviews;
- recruit 3–5 QR pilot wineries;
- create manual QR/Passport mobile prototype;
- test occasion vs taste discovery with 10 users.

### Week 4

- synthesize evidence;
- decide whether primary hypothesis survives;
- finalize Wine Vision target list/interview calendar if timing aligns;
- run corporate gift landing/outreach preparation.

### 30-day gate

Continue only if supply commitment + real pain are visible.

---

## Days 31–60 — Concierge and QR pilot

### Week 5–6

- onboard 5–10 wineries manually;
- verify data and content rights;
- start concierge wine-day planning for real users;
- place QR at 3–5 locations;
- measure exposure -> save.

### Week 7–8

- structured booking/request pilot;
- response SLA tracking;
- continue QR cohort;
- first corporate-gift outreach to 20–30 businesses;
- identify 2 payment/acquiring providers for discovery calls.

### 60-day gate

Need:

- real winery actions;
- acceptable QR/save behavior;
- manageable data operations;
- at least early monetization interest.

If not, narrow/pivot before coding platform.

---

## Days 61–90 — Repeat signal + MVP decision

### Week 9–10

- send consented reorder follow-ups to earliest cohort;
- measure clicks/inquiries/orders;
- retest strongest consumer workflow;
- ask pilot wineries for paid continuation willingness.

### Week 11

- pricing interview / offer real plan;
- collect first paid commitments if value exists;
- legal/payment architecture discovery only for flows now justified.

### Week 12–13

Decision review:

### Option A — Build MVP

Only if QR/repeat/booking value is proven enough.

### Option B — Narrow B2B repeat-purchase tool

If consumer discovery is weak but post-visit retention is strong.

### Option C — Corporate-gift pivot

If B2B orders show stronger economics.

### Option D — Stop

If neither supply nor demand demonstrates payment-worthy pain.

## 90-day expected deliverables

- interview evidence ledger;
- 10+ verified partner profiles;
- real QR cohort data;
- booking/request conversion data;
- repeat-purchase signal;
- at least one real pricing test;
- corporate-gift signal;
- go/no-go decision;
- only then implementation backlog.

## Resource allocation recommendation

First 90 days:

- 35% customer/supply research;
- 25% partner sales/onboarding;
- 15% data curation;
- 10% lightweight prototypes/automation;
- 10% analytics/synthesis;
- 5% legal/payment discovery.

If engineering consumes 60–80% of the first 60 days, strategy is being executed incorrectly.
