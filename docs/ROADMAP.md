# Canonical Roadmap

This roadmap is intentionally validation-first. Detailed research roadmap: `research/2026-09-15/15_GATE_BASED_ROADMAP.md`.

## Phase 0 — Desk due diligence

**Done:** research package completed and QA-reviewed.

## Phase 1 — Winery + consumer validation

**Now**

- execute winery interviews;
- execute consumer workflow interviews;
- audit digital maturity and data ownership;
- secure concrete pilot commitments;
- prepare Wine Vision field research.

Exit: G1 + G2 evidence.

## Phase 2 — Concierge validation

- manually plan winery days;
- test structured booking/request;
- measure winery response;
- test occasion vs technical Taste UX;
- time-track supply onboarding.

No production app.

## Phase 3 — QR Passport + repeat loop

- deploy smallest mobile-web QR prototype;
- save exact wine/vintage;
- consented 30/60-day follow-up;
- track direct reorder/contact outcome.

Exit: G3 + G4.

## Phase 4 — First paid pilot

- offer subscription, action fee or hybrid;
- measure first real payer behavior;
- decide whether product is primarily demand-gen, retention tool or booking layer.

Exit: G5.

## Phase 5 — Technical MVP

Only after G1–G5 sufficiently pass.

Implement the narrow winning workflow; not the long-term platform vision.

## Phase 6+ — Optional expansions

Transactional booking -> G6  
Commerce -> G7  
Native mobile -> G8  
Region -> G9

Any failing gate can cause pivot or stop.
