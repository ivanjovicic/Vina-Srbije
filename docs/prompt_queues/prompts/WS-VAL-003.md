# WS-VAL-003 — Winery Digital Maturity & Data-Maintenance Audit

**Status:** READY  
**Gate:** G1 / data feasibility

## Global rules

- Read `AGENTS.md`, `docs/VALIDATION_GATES.md`, `docs/DECISION_LOG.md`, and relevant research before starting.
- This is validation work, not product implementation.
- Use FACT / ESTIMATE / ASSUMPTION / HYPOTHESIS / UNKNOWN.
- Current claims require source + access date.
- Do not fabricate interview data, willingness-to-pay, bookings, conversion, or user behavior.
- If real-world evidence is unavailable, produce the research instrument/work package and mark execution as pending.
- Create/update a run log under `.ai/runs/`.

## Objective

Determine the serviceable supply universe and real maintenance burden.

## Sample

30–50 wineries across pilot clusters and maturity bands.

## Capture

- website/mobile;
- Serbian/English;
- Google/Maps;
- social;
- tasting offer;
- price;
- reservation method;
- restaurant/stay;
- shop/reorder;
- current wines/vintages;
- named data owner;
- response time;
- last observed update;
- content rights/contact permission where known.

## Outputs

- `data/winery_digital_maturity_sample.csv`
- scoring method;
- limitations;
- pilot segment recommendation;
- estimated onboarding/update workload;
- fields that must never be represented as live without re-verification.

Do not extrapolate the sample to all 529 registered wineries without a justified sampling model.
