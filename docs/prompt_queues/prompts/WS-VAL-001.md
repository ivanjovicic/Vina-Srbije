# WS-VAL-001 — Winery Pain & Payer Audit

**Status:** READY  
**Gate:** G1  
**Primary objective:** determine whether acquisition, booking or post-tasting repeat purchase is a material business problem for tourism-ready Serbian wineries.

## Global rules

- Read `AGENTS.md`, `docs/VALIDATION_GATES.md`, `docs/DECISION_LOG.md`, and relevant research before starting.
- This is validation work, not product implementation.
- Use FACT / ESTIMATE / ASSUMPTION / HYPOTHESIS / UNKNOWN.
- Current claims require source + access date.
- Do not fabricate interview data, willingness-to-pay, bookings, conversion, or user behavior.
- If real-world evidence is unavailable, produce the research instrument/work package and mark execution as pending.
- Create/update a run log under `.ai/runs/`.

## Scope

Prepare and execute, when real access is available, 20–30 structured interviews across:
- Fruška Gora/Srem;
- Šumadija/Topola;
- optional control sample outside pilot clusters;
- small/family, premium/tourism, digitally mature and digitally immature wineries.

## Required preparation

1. target list with reason for inclusion;
2. 10–15 minute interview script based on `04_CUSTOMERS_AND_JTBD.md`;
3. evidence capture schema;
4. explicit pilot ask;
5. pricing/payer probe only after existing workflow/pain is understood.

## Required outputs

- `docs/validation/WS-VAL-001_WINERY_INTERVIEWS.md`
- anonymized evidence table;
- pain ranking;
- current workflow map;
- quantification where interviewee actually knows numbers;
- pilot commitments and exact commitment type;
- objections;
- willingness-to-pay evidence separated from polite interest;
- G1 recommendation: PASS / CONTINUE / FAIL.

## Stop rules

- Never convert “zanimljivo” into a pilot commitment.
- Never infer nationwide prevalence from a convenience sample.
- If fewer than 10 real interviews are available, do not issue a PASS.
