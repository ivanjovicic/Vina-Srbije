## Global rules

- Read `AGENTS.md`, `docs/VALIDATION_GATES.md`, `docs/DECISION_LOG.md`, and relevant research before starting.
- This is validation work, not product implementation.
- Use FACT / ESTIMATE / ASSUMPTION / HYPOTHESIS / UNKNOWN.
- Current claims require source + access date.
- Do not fabricate interview data, willingness-to-pay, bookings, conversion, or user behavior.
- If real-world evidence is unavailable, produce the research instrument/work package and mark execution as pending.
- Create/update a run log under `.ai/runs/`.

## Objective

Use Wine Vision to test top assumptions efficiently. This is not generic networking.

## Before event

- shortlist 40–60 target exhibitors by segment;
- pre-contact at least 15;
- map booth/route where data exists;
- create 10-minute winery script;
- create buyer/distributor script;
- create QR/mobile evidence form;
- define pilot ask;
- define daily synthesis template.

## During event targets

Per day:
- 10–15 high-quality winery conversations;
- 3–5 buyer/tourism/HORECA conversations;
- concrete examples of booking/DTC/repeat workflows;
- explicit pilot asks.

## Evidence hierarchy

Strong:
- agrees to pilot;
- provides responsible contact;
- provides data;
- agrees to QR placement/outcome measurement.

Weak:
- business card;
- “javi se”;
- positive product opinion.
